## 3D Tools

### CAD, Modeling & Blockout

- [Plasticity](https://www.plasticity.xyz/): NURBS modeling CAD tool built for concept artists and hard-surface workflows alongside Blender. `[paid · open-source]` ([Repository](https://github.com/nkallen/plasticity))
- [FreeCAD](https://www.freecad.org/): Open-source parametric 3D CAD modeler suitable for precision mechanical parts and 3D printing exported to Blender. `[open-source]` ([Repository](https://github.com/FreeCAD/FreeCAD))
- [Blockbench](https://blockbench.net/): Open-source low-poly and pixel-textured 3D model editor with native glTF/OBJ workflows for Blender and game engines. `[GPL]` ([Repository](https://github.com/JannisX11/blockbench))
- [TrenchBroom](https://trenchbroom.github.io/): Open-source brush-based 3D level editor widely used for fast architectural blockouts and indie game environments exported to Blender. `[GPL]` ([Repository](https://github.com/TrenchBroom/TrenchBroom))
- [Sweet Home 3D](https://www.sweethome3d.com/): Free interior design application for drawing floor plans, arranging furniture, and exporting 3D room layouts. `[open-source]` ([Repository](https://sourceforge.net/projects/sweethome3d/files/))

### Mesh Processing, Retopology & Voxels

- [MeshLab](https://www.meshlab.net/): Open-source system for processing, cleaning, and converting 3D triangular meshes. `[open-source]` ([Repository](https://github.com/cnr-isti-vclab/meshlab))
- [CloudCompare](https://www.cloudcompare.org/): Open-source 3D point-cloud and triangular mesh processing suite for scan alignment, inspection, and decimation. `[GPL]` ([Repository](https://github.com/CloudCompare/CloudCompare))
- [Instant Meshes](https://github.com/wjakob/instant-meshes): Interactive field-aligned quad/triangle remeshing tool. `[open-source]`
- [MagicaVoxel](https://ephtracy.github.io/index.html?page=mv_main): Free lightweight 8-bit voxel art editor and GPU-based interactive path-tracing renderer.
- [Goxel](https://github.com/guillaumechereau/goxel): Open-source 3D voxel editor with `.obj`, `.ply`, `.gltf`, and MagicaVoxel export support. `[GPL]`

### Characters, Sculpting, Rigging & Animation

- [Nomad Sculpt](https://nomadsculpt.com/): Popular portable sculpting and vertex-painting application for iPad, Android, and desktop with clean exports to Blender. `[paid]`
- [Cascadeur](https://cascadeur.com/): Physics-assisted standalone 3D keyframe animation software for humanoid and creature characters (free non-commercial tier and paid Pro plans).
- [VRoid Studio](https://vroid.com/en/studio): Free 3D character creator specializing in anime-style avatars with direct `.vrm` export to Blender.
- [AccuRIG](https://actorcore.reallusion.com/auto-rig): Free standalone auto-rigging application for humanoid characters with FBX/Blender export presets.

### Simulation, Camera, Lighting & Web 3D

- [EmberGen](https://jangafx.com/software/embergen): Real-time volumetric fire, smoke, and explosion simulator exporting `.vdb` volumes and flipbooks for Blender (companion real-time liquid simulator: [LiquiGen](https://jangafx.com/software/liquigen)). `[paid]` ([LiquiGen](https://jangafx.com/software/liquigen))
- [fSpy](https://fspy.io/): Open-source standalone still-image camera matching app for calibrating perspective and focal length before importing into Blender. `[GPL]` ([Repository](https://github.com/stuffmatic/fSpy))
- [HDR Light Studio](https://www.lightmap.co.uk/): Interactive HDRI and area-light design software with live connection support for Blender. `[paid]`
- [Spline](https://spline.design/): Browser-based 3D design and interactive web experience tool.

## Various Tools

### Reference Boards & Media Review

- [PureRef](https://www.pureref.com/): Simple way to view and organize your reference images.
- [Allusion](https://allusion-app.github.io/): Organizer for your entire collection of references, inspiration and any other kinds of images. `[open-source]` ([Repository](https://github.com/allusion-app/Allusion))
- [Connecter](https://connecterapp.com/): Free visual digital asset management (DAM) desktop application for 3D models, materials, and AEC libraries.
- [DJV](https://grizzlypeak3d.github.io/DJV/): Professional image sequence, media review software for VFX, animation, and film production. `[open-source]` ([Repository](https://github.com/grizzlypeak3d/DJV))
- [Exr-IO](https://www.exr-io.com/): Robust and exact solution for dealing with multi-layer EXR pictures. It supports Cryptomatte.
- [GameTextureViewer](https://jangafx.com/software/gametextureviewer/): Fast, reliable, and simple tool for artists to preview textures and sprite sheet animations on the fly.

### Shaders, Particles & 3D Viewers

- [SHADERed](https://github.com/dfranx/SHADERed): Lightweight tool for creating and testing HLSL and GLSL shaders. `[open-source]`
- [CineShader](https://cineshader.com/editor): CineShader is a real-time 3D shader visualiser. It leverages the _Shadertoy_ API to bring thousands of existing shader artworks into a cinematic 3D environment.
- [Light Tracer Render](https://lighttracer.org/): Provides you with everything you need to create photorealistic renderings interactively, in both desktop Web browsers and Windows application.
- [Effekseer](https://effekseer.github.io/en/): Open source particle effect creating tool.
- [Particle Illusion](https://borisfx.com/products/particle-illusion/): Free GPU-accelerated 2D particle generator.
- [F3D](https://f3d.app): Fast and minimalist open source cross-platform 3D viewer. Support many fileformats and rendering style. `[open-source]` ([Repository](https://github.com/f3d-app/f3d))
- [Processing](https://processing.org/): Flexible software sketchbook and a language for learning how to code within the context of the visual arts. `[open-source]` ([Repository](https://github.com/processing/processing))

### Blender Tools & Custom Builds

- [Goo Engine](https://github.com/dillongoostudios/goo-engine): Custom open-source build of Blender by DillonGoo Studios tailored for 3D anime and Non-Photorealistic Rendering (NPR). `[GPL]`
- [UPBGE](https://upbge.org/): Open-source standalone 3D game engine forked from Blender and distributed as a custom Blender build. `[open-source]` ([Repository](https://github.com/UPBGE/upbge))
- [Bforartists](https://www.bforartists.de/): Open-source Blender fork focused on streamlined UI ergonomics, menus, and discoverable workflows. `[open-source]` ([Repository](https://github.com/Bforartists/Bforartists))
- [BlenderUpdater](https://github.com/overmindstudios/BlenderUpdater): Download and install nightly builds with one click. `[open-source]`
- [BlenderUpdaterCLI](https://github.com/overmindstudios/BlenderUpdaterCLI): Command line version of BlenderUpdater. `[open-source]`
- [Blender Launcher V2](https://github.com/Victor-IX/Blender-Launcher-V2): Standalone client for managing official builds of Blender. `[open-source]`
- [Blender Manager](https://github.com/verlorengest/BlenderManager): Auto-Update, Project Management and Time Tracking, Addon Control, Version Handling, Render Management, and More. `[open-source]`
- [Sheep it Render Farm](https://www.sheepit-renderfarm.com/): Free distributed render farm for Blender.

## Photogrammetry

- [Meshroom](https://alicevision.org/#meshroom): Free, open-source 3D Photogrammetry Software. `[open-source]` ([Repository](https://github.com/alicevision/meshroom))
- [COLMAP](https://colmap.github.io/): Reconstruct 3D models from ordered or unordered image collections automatically. `[open-source]` ([Repository](https://github.com/colmap/colmap))
- [3DF Zephyr Free](https://www.3dflow.net/3df-zephyr-free/): Is free version of 3DF Zephyr photogrammetry software for personal use. It comes with some limitations.
- [MicMac](https://github.com/micmacIGN/micmac): Free open-source photogrammetric suite that can be used in a variety of 3D reconstruction scenarios. `[open-source]`
- [RealityScan](https://www.realityscan.com/): Unified desktop and mobile photogrammetry suite by Epic Games (formerly RealityCapture), free under indie/small-revenue thresholds.
- [Agisoft Metashape](https://www.agisoft.com/): Stand-alone software product that performs photogrammetric processing of digital images and generates 3D spatial data. `[paid]`
- [Postshot](https://www.jawset.com/): Standalone desktop application for training and editing 3D Gaussian Splatting (`.ply`) and radiance field scenes ready for Blender.
- [Nerfstudio](https://github.com/nerfstudio-project/nerfstudio): Open-source studio for training, editing, and exporting NeRF and 3D Gaussian Splatting scenes. `[open-source]`
- [SuperSplat](https://superspl.at/editor): Free browser-based 3D Gaussian Splat editor for inspecting, cropping, cleaning, and exporting splat scenes. `[MIT]` ([Repository](https://github.com/playcanvas/supersplat))
- [Brush](https://github.com/ArthurBrussee/brush): Cross-platform 3D reconstruction and Gaussian Splatting training engine supporting real-time rendering. `[open-source]`
- [gsplat](https://docs.gsplat.studio/main/): Open-source CUDA-accelerated rasterization library for training and rendering 3D Gaussian Splats. `[open-source]` ([Repository](https://github.com/nerfstudio-project/gsplat))

## Texture/Material

- [Material Maker](https://www.materialmaker.org/): Open-source node-based procedural PBR material authoring and 3D model texture painting application built with Godot. `[MIT]` ([Repository](https://github.com/RodZill4/material-maker))
- [ArmorPaint](https://armorpaint.org/): Open-source 3D PBR texture painting application with node-based brushes and GPU map baking. `[open-source]` ([Repository](https://github.com/armory3d/armorpaint))
- [InstaMAT](https://www.instamaterial.com/): Node-based material authoring, layered 3D texturing, and GPU mesh baking suite (free Pioneer license for individuals/indies under $100k revenue).
- [Materialize](https://boundingboxsoftware.com/materialize/): Open-source tool for generating tileable diffuse, height, normal, AO, and metallic PBR texture maps from a single image. `[GPL]` ([Repository](https://github.com/BoundingBoxSoftware/Materialize))
- [Normal Map Bench](https://normalmapbench.com/): Free browser-based normal map generator from images with live strength, smoothing, edge and lighting controls; OpenGL/DirectX export.
- [Agisoft De-Lighter](https://agisoft.freshdesk.com/support/solutions/articles/31000158376-agisoft-texture-de-lighter-general-workflow): Free standalone utility for removing baked shadows and ambient lighting from photogrammetry textures. [[download]](https://www.agisoft.com/downloads/installer/)
- [Architextures](https://architextures.org/create): Browser-based generator for seamless architectural textures, bump maps, and CAD hatch patterns.
- [NVIDIA Texture Tools Exporter](https://developer.nvidia.com/texture-tools-exporter): CUDA-accelerated standalone compressor and mipmap generator exporting `.dds` and `.ktx2` textures.
- [Agama Materials](https://agama.itch.io/agama-materials): Freeware desktop tool for creating procedural PBR materials and painting directly on 3D models.

## Terrain, GIS & LiDAR

### Terrain Generators

- [TerreSculptor](https://www.demenzunmedia.com/home/terresculptor/): Freeware terrain creation, heightmap editing, and erosion processing software.
- [World Machine](https://www.world-machine.com/): Procedural terrain, erosion, heightmap, and mesh generator for games and 3D scenes (free Basic Edition available).
- [Terragen](https://planetside.co.uk/free-downloads/): Ray-tracing terrain and atmosphere generator (free non-commercial edition available).
- [World Creator](https://www.bitethebytes.com/products/world-creator): Real-time GPU-accelerated terrain and landscape generator. `[paid]`
- [Gaea](https://quadspinner.com/): Node-based terrain and environment design suite for VFX and games (free Community Edition available).
- [Instant Terra](https://www.wysilab.com/): Real-time node-based terrain generation tool for large worlds, games, and simulations.

### Real-World DEM & LiDAR Data

- [Tangram Heightmapper](https://tangrams.github.io/heightmapper/): Interactive global grayscale heightmap browser for exporting elevation maps into 3D applications.
- [OpenTopography](https://portal.opentopography.org/datasets): Collaborative Earth-science portal providing high-resolution LiDAR point clouds and DEM topography datasets.
- [Copernicus DEM - ESA](https://dataspace.copernicus.eu/explore-data/data-collections/copernicus-contributing-missions/collections-description/COP-DEM): Global Digital Surface Model (DSM) from the European Space Agency covering terrain, buildings, and vegetation.
- [NOAA Data Access Viewer](https://coast.noaa.gov/dataviewer/#/lidar/search/): Search and download coastal LiDAR, aerial imagery, and land-cover datasets.
- [USGS National Map & LiDAR](https://apps.nationalmap.gov/downloader/): U.S. Geological Survey elevation and LiDAR downloader, alongside [Earth Explorer](https://earthexplorer.usgs.gov/) and the browser-based [USGS Entwine Point Cloud Viewer](https://usgs.entwine.io/). `[open-source]` ([Earth Explorer](https://earthexplorer.usgs.gov/), [USGS Entwine Point Cloud Viewer](https://usgs.entwine.io/), [Repository](https://github.com/hobuinc/usgs-lidar))

- [Natron](https://natrongithub.github.io/): Open-source node-based compositing software for VFX and motion-graphics multi-pass rendering workflows. `[GPL]` ([Repository](https://github.com/NatronGitHub/Natron))
- [Krita](https://krita.org/en/): Professional free and open-source digital painting and texture editing application. `[GPL]` ([Repository](https://github.com/KDE/krita))
- [Inkscape](https://inkscape.org/): Open-source vector graphics editor ideal for preparing `.svg` profiles, curves, decals, and trim sheets for Blender. `[GPL]` ([Repository](https://gitlab.com/inkscape/inkscape))
- [Audacity](https://www.audacityteam.org/): Free, open-source, cross-platform multi-track audio editor and recorder. `[GPL]` ([Repository](https://github.com/audacity/audacity))
