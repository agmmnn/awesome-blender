## 3D Tools

### Mesh Processing, Retopology & Voxels

- [MeshLab](https://www.meshlab.net/): Open source system for processing and editing 3D triangular meshes. `[open-source]` ([Repository](https://github.com/cnr-isti-vclab/meshlab))
- [AutoRemesher](https://github.com/huxingyi/autoremesher): Open-source auto-retopology tool intended to convert source meshes into clean, animation-friendly all-quad geometry. `[open-source]`
- [Instant Meshes](https://github.com/wjakob/instant-meshes): Interactive field-aligned mesh generator. `[open-source]`
- [Magica Voxel](https://ephtracy.github.io/index.html?page=mv_main): A free lightweight 8-bit voxel art editor and GPU based interactive path tracing renderer.
- [Goxel](https://github.com/guillaumechereau/goxel): Create voxel graphics. Export to obj, pyl, png, magica voxel, qubicle. `[open-source]`
- [aerialod](https://ephtracy.github.io/index.html?page=aerialod): A free interactive path tracing renderer for height maps.

### Characters, Sculpting, Rigging & Animation

- [VRoid Studio](https://vroid.com/en/studio): A 3D character maker that specializes in Japanese anime-like expressions.
- [AccuRIG](https://actorcore.reallusion.com/auto-rig): Free application designed for fast and easy character rigging.
- [Cascadeur](https://cascadeur.com/): Standalone software for creating keyframe animation of 3D characters, humanoid or otherwise. _Free for early adopters._
- [Nomad Sculpt](https://nomadsculpt.com/): Popular portable sculpting and vertex-painting application for iPad, Android, and desktop with clean exports to Blender. `[paid]`

### Modeling, Architecture, Volumetrics & Scene Tools

- [fSpy](https://fspy.io/): Open-source standalone still-image camera matching app for matching perspective and focal length before importing into Blender.
- [UPBGE](https://upbge.org/): Open-source standalone 3D game engine forked from Blender and bundled as a custom Blender build. `[open-source]` ([Repository](https://github.com/UPBGE/upbge))
- [Blockbench](https://www.blockbench.net/): Open-source low-poly and pixel-textured 3D model editor with native glTF/OBJ workflows for Blender and game engines. `[GPL]` ([Repository](https://github.com/JannisX11/blockbench))
- [Plasticity](https://www.plasticity.xyz/): NURBS modeling CAD tool built for concept artists and hard-surface workflows alongside Blender. `[paid · open-source]` ([Repository](https://github.com/nkallen/plasticity))
- [FreeCAD](https://www.freecad.org/): Open-source parametric 3D CAD modeler suitable for precision mechanical parts and 3D printing exported to Blender. `[open-source]` ([Repository](https://github.com/FreeCAD/FreeCAD))
- [Dust3D](https://dust3d.org/): Cross-platform open-source modeling software. It helps you create a 3D watertight model in seconds.
- [Sweet Home 3D](https://www.sweethome3d.com/): Free interior design application that helps you draw the plan of your house, arrange furniture on it and visit the results in 3D. `[open-source]` ([Repository](https://sourceforge.net/projects/sweethome3d/files/))
- [Spline](https://spline.design/): Easily create and publish 3D web experiences. Build and iterate fast with production-ready results.
- [TreeIt](https://www.evolved-software.com/treeit/treeit): Easy to use real time 3D tree generator for the simple creation.
- [EmberGen](https://jangafx.com/software/embergen/): Real-time volumetric fluid simulation tool that can instantly simulate, render, and export flipbooks, image sequences, and VDB volumes. `[paid]`
- [HDR Light Studio](https://www.lightmap.co.uk/): Lets you easily create and edit HDR lighting with your existing 3D software. `[paid]`
- [CNDL](https://cndl.io/): An IES lighting creation toolset. Improve your renders with custom IES lighting.
- [Connecter](https://connecterapp.com/): Free and visual creative assets management for 3d, AEC and design professionals.
- [Phototiler](https://halfmaps.itch.io/phototiler): Lightweight photorealistic map renderer that allows quick rendering of 3D maps for creative cartography.

## Various Tools

- [DJV](https://grizzlypeak3d.github.io/DJV/): Professional image sequence, media review software for VFX, animation, and film production. `[open-source]` ([Repository](https://github.com/grizzlypeak3d/DJV))
- [Exr-IO](https://www.exr-io.com/): Robust and exact solution for dealing with multi-layer EXR pictures. It supports Cryptomatte.
- [GameTextureViewer](https://jangafx.com/software/gametextureviewer/): Fast, reliable, and simple tool for artists to preview textures and sprite sheet animations on the fly.

- [F3D](https://f3d.app): Fast and minimalist open source cross-platform 3D viewer. Support many fileformats and rendering style. `[open-source]` ([Repository](https://github.com/f3d-app/f3d))
- [Processing](https://processing.org/): Flexible software sketchbook and a language for learning how to code within the context of the visual arts. `[open-source]` ([Repository](https://github.com/processing/processing))

## Photogrammetry

- [Meshroom](https://alicevision.org/#meshroom): Free, open-source 3D Photogrammetry Software. `[open-source]` ([Repository](https://github.com/alicevision/meshroom))
- [COLMAP](https://colmap.github.io/): Reconstruct 3D models from ordered or unordered image collections automatically. `[open-source]` ([Repository](https://github.com/colmap/colmap))
- [3DF Zephyr Free](https://www.3dflow.net/3df-zephyr-free/): Is free version of 3DF Zephyr photogrammetry software for personal use. It comes with some limitations.
- [MicMac](https://github.com/micmacIGN/micmac): Free open-source photogrammetric suite that can be used in a variety of 3D reconstruction scenarios. `[open-source]`
- [RealityScan](https://www.realityscan.com/): Unified desktop and mobile photogrammetry suite by Epic Games (formerly RealityCapture), free under indie/small-revenue thresholds.
- [Agisoft Metashape](https://www.agisoft.com/): Stand-alone software product that performs photogrammetric processing of digital images and generates 3D spatial data. `[paid]`
- [Postshot](https://www.jawset.com/): Standalone desktop application for training and editing 3D Gaussian Splatting (`.ply`) and radiance field scenes ready for Blender.
- [Nerfstudio](https://github.com/nerfstudio-project/nerfstudio): Open-source studio for training, editing, and exporting NeRF and 3D Gaussian Splatting scenes. `[open-source]`
- [SuperSplat](https://superspl.at/editor): Free browser-based 3D Gaussian Splat editor for inspecting, cropping, cleaning, and exporting splat scenes. `[MIT]` ([Repository](https://github.com/playcanvas/supersplat))
- [Brush](https://github.com/ArthurBrussee/brush): Cross-platform 3D reconstruction and Gaussian Splatting training engine supporting real-time rendering. `[open-source]`
- [gsplat](https://docs.gsplat.studio/main/): Open-source CUDA-accelerated rasterization library for training and rendering 3D Gaussian Splats. `[open-source]` ([Repository](https://github.com/nerfstudio-project/gsplat))

## Texture/Material

- [ArmorPaint](https://armorpaint.org/): Open-Source 3D PBR Texture Painting Software. `[open-source]` ([Repository](https://github.com/armory3d/armorpaint))
- [NVIDIA Texture Tools Exporter](https://developer.nvidia.com/texture-tools-exporter): Allows users to create highly compressed texture files (that stay small both on disk and in memory) directly from image sources using NVIDIA’s CUDA-accelerated Texture Tools compressor technology.
- [Materialize](https://boundingboxsoftware.com/materialize/): Stand alone tool for creating materials from images. `[open-source]` ([Repository](https://github.com/BoundingBoxSoftware/Materialize))
- [Material Maker](https://rodzilla.itch.io/material-maker): Simple procedural materials generation tool. `[open-source]` ([Repository](https://github.com/RodZill4/material-maker))
- [TextureLab](https://njbrown.itch.io/texturelab): Tool designed to make procedural texture generation.
- [Agisoft De-Lighter](https://agisoft.freshdesk.com/support/solutions/articles/31000158376-agisoft-texture-de-lighter-general-workflow): Free stand-alone tool designed to remove shadows from model textures. [[download]](https://www.agisoft.com/downloads/installer/)
- [Agama Materials](https://agama.itch.io/agama-materials): Is software for creating PBR materials and painting 3d models. You can create materials and use them for painting models, or you can use pre-made textures.
- [Architextures - Create](https://architextures.org/create): Web app allows you to create seamless textures, bump maps and CAD hatches. Select any of the parameters to get started.
- [Normal Map Bench](https://normalmapbench.com/): Free browser-based normal map generator from images with live strength, smoothing, edge and lighting controls; OpenGL/DirectX export.

## Terrain & Height Maps

### Terrain Generators

- [TerreSculptor](https://www.demenzunmedia.com/home/terresculptor/): Terrain creation and editing software. It is freeware.
- [World Machine](https://www.world-machine.com/): Command powerful tools like erosion and advanced colormaps to create terrain heightmaps, meshes, and textures for your game or 3D scene. You can use the Basic Edition for free.
- [Terragen](https://planetside.co.uk/free-downloads/): Ray-tracing supported terrain generator. There is free version with some limitations.
- [World Creator](https://www.bitethebytes.com/products/world-creator): Real-time terrain generator and landscape generator. `[paid]`
- [Gaea](https://quadspinner.com/): Sophisticated and modern terrain design software for apex results in moments. There is Community Free edition with some limitations.
- [Instant Terra](https://www.wysilab.com/): Real-time terrain generation tool. Create your terrain, world, and landscape for your game, movie, or simulation.

### Real-World Height Maps

- [Tangram Heightmapper](https://tangrams.github.io/heightmapper/): Interactive grayscale heightmap browser, which can generate heightmaps for use in 3D applications.
- [OpenTopography/datasets](https://portal.opentopography.org/datasets): Facilitates community access to high-resolution, Earth science-oriented, topography data, and related tools and resources. _Registration required_.
- [Copernicus DEM - ESA](https://dataspace.copernicus.eu/explore-data/data-collections/copernicus-contributing-missions/collections-description/COP-DEM): The Copernicus Digital Elevation Model is a Digital Surface Model (DSM) that represents the surface of the Earth including buildings, infrastructure and vegetation.
