## Simulation/Physics

- [FLIP Fluids](https://github.com/rlguy/Blender-FLIP-Fluids): Powerful liquid simulation plugin that gives you the ability to create high quality fluid effects all within Blender, the free and open source 3D creation suite. `[open-source]` ([Superhive](https://superhivemarket.com/products/flipfluids))
- [MolecularNodes](https://extensions.blender.org/add-ons/molecularnodes/): Import, animate, and simulate molecular biology and structural data inside Blender using Geometry Nodes. `[GPL · ext:molecularnodes]` ([Repository](https://github.com/BradyAJohnston/MolecularNodes))
- [Molecular+](https://github.com/u3dreal/molecular-plus): Modernized continuation of the [Molecular Script](https://github.com/scorpion81/Blender-Molecular-Script) add-on for particle collisions, linking, and physics simulations in Blender 4.x. `[GPL]` ([Molecular Script](https://github.com/scorpion81/Blender-Molecular-Script))
- [projectile](https://github.com/develeon/projectile): An artist-friendly tool for throwing stuff around inside blender. `[open-source]`
- [Phobos](https://github.com/dfki-ric/phobos): An add-on for Blender allowing to create URDF, SDF and SMURF robot models. `[open-source]`
- [Blender Optics Simulator](https://github.com/emircbngl/blender-optics-simulator): An add-on that turns Blender into a physics-checked optical bench: live beam tracing with polarization and Gaussian-beam propagation, real opto-mechanical mounts, and a headless Python API. `[GPL]`
- [Stop-motion-OBJ](https://github.com/neverhood311/Stop-motion-OBJ): Import sequences of `.obj`, `.ply`, or `.stl` mesh files (such as external fluid or particle simulations) as animated mesh sequences in Blender. `[GPL]`
