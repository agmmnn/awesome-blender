# AI & MCP

> 38 curated entries across 3 categories. Index: https://awesome-blender.vercel.app/llms.txt

## MCP, Agents & Skills

- [BlenderMCP](https://github.com/ahujasid/mcp-for-blender): Connects Blender to Claude AI and other MCP clients through the Model Context Protocol for prompt-assisted 3D modeling, scene creation, and manipulation. `[MIT]`
- [FastMCP for Blender](https://github.com/sandraschi/blender-mcp): Headless Blender automation server via FastMCP with 41 tools covering mesh, VSE, Grease Pencil, and VRM workflows. `[MIT]`
- [blender-kiln](https://github.com/elithril/blender-kiln): A Claude Code plugin that drives Blender through an MCP server to build, texture, optimize, and export game-ready assets from a text brief or a photo. `[MIT]`
- [Blender Agent Skills](https://github.com/EL4CTEO/blender-skills): Professional Blender workflows packaged as Agent Skills for Claude Code, Cursor, Copilot, and Gemini CLI. `[MIT]`
- [DESIGN:OS 3D Blender](https://github.com/jangtrinh/design-os-3d-blender): Agent toolkit that lets AI coding agents build models in Blender with a `bpy` knowledge base, an execution contract, and a 3D-print production gate. `[open-source]`
- [AnyScene](https://github.com/apekshik/anyscene): Multi-agent pipeline that generates complete, photorealistic 3D Blender scenes from a text prompt, handling prop generation, room layout, atmosphere, and cinematic rendering. [[video demo]](https://x.com/apekshik/status/2116638903923073290) `[MIT]`
- [AI Art Engine](https://github.com/Justin-sky/ai-art-engine): Node-based game asset studio with a built-in Blender TCP bridge and 24 dedicated MCP tools for 3D mesh modeling, armature rigging, PBR baking, and glTF/FBX export to Unity, Godot, and Cocos. `[GPL]`
- [Construct for Blender](https://github.com/rtmandreyev/construct/tree/main/hosts/blender): Imports constructs written by AI agents (scene JSON, worlds or glTF) with their named parts, joints and assembly, with sidebar controls for build, opening, hologram to solid and finish, and keyframed reveals. `[open-source]` ([Repository](https://github.com/rtmandreyev/construct))
- [Mixar](https://www.mixar.app/): AI-powered 3D suite built as a custom fork of Blender with an integrated chat agent (Mixie), layer-based texture painting, and generative 3D tools. `[GPL]` ([Repository](https://github.com/Mixar-AI/mixar-app))
- [Blender Agent Studio](https://github.com/ifBars/blender-agent-studio): Open-source Blender AI plugin and skill suite for Claude Code and Codex that produces editable `.blend` scenes, Python scripts, and visually reviewed renders locally. `[MIT]`
- [blender-mcp-bridge](https://github.com/seehiong/blender-mcp-bridge): MCP bridge with 93 tools for Blender modeling, sculpting, architecture/MEP, materials, and 3D-print prep, plus a visual record/replay session editor. `[MIT]`
- [bpy-dev/blender-mcp](https://github.com/bpy-dev/blender-mcp): Enhanced Blender MCP distribution offering standalone `bpy` execution, runtime API documentation lookup, and benchmark tooling. `[GPL]`
- [Blender Assembly Skill](https://github.com/ProfRino/Blender-MCP-Assembly-Skill): Geometry-planning agent skill for Blender MCP workflows that verifies connections, primitive scaling, rotations, and object overlaps to prevent common AI modeling errors. `[open-source]`
- [dcc-mcp-blender](https://github.com/dcc-mcp/dcc-mcp-blender): Typed Blender MCP add-on in the multi-DCC `dcc-mcp` ecosystem enabling AI agents to model, edit UVs, rig, build materials, and render scenes. `[MIT]`

## Generative 3D & ComfyUI

- [ComfyUI-BlenderAI-node](https://github.com/AIGODLIKE/ComfyUI-BlenderAI-node): Popular node-based ComfyUI integration inside Blender for AI model generation, texture enhancement, and AI-assisted rendering. `[GPL]`
- [BlenderAIStudio](https://github.com/AIGODLIKE/BlenderAIStudio): Next-generation AI workflow studio add-on for Blender built on the Addon UI-Forge framework by AIGODLIKE. `[GPL]`
- [ComfyUI-Blender](https://github.com/alexisrolland/ComfyUI-Blender): Blender add-on to run ComfyUI workflows directly inside Blender for AI texture, image, and 3D asset generation. `[open-source]`
- [Scenario for Blender](https://github.com/scenario-labs/blender-plugin): AI image, video, 3D, and PBR material generation in the viewport, plus a local MCP server for agents. `[GPL]`
- [UniRig](https://github.com/VAST-AI-Research/UniRig): Universal AI automatic skeletal rigging and skinning framework (SIGGRAPH 2025) by Tsinghua & VAST with Blender workflow and VRM add-on integration. `[MIT]`
- [Tripo 3D for Blender](https://github.com/Tripo-Developer/tripo-3d-for-blender): Official open-source Blender extension for Tripo AI enabling Text/Image-to-3D generation and textured, rig-ready asset imports inside the viewport sidebar. `[MIT]`
- [Meshy for Blender](https://docs.meshy.ai/en/webapp/plugins/blender/introduction): Official local bridge plugin from Meshy AI for sending static or rigged/animated 3D assets directly into Blender alongside mesh cleanup and 3D-print tools. `[paid]`
- [trellisblender](https://github.com/FishWoWater/trellis_blender): Blender sidebar integration for Microsoft's [TRELLIS](https://github.com/microsoft/TRELLIS) and [TRELLIS.2](https://github.com/microsoft/TRELLIS.2) models supporting local Text-to-3D and Image-to-3D generation. `[open-source]` ([TRELLIS](https://github.com/microsoft/TRELLIS), [TRELLIS.2](https://github.com/microsoft/TRELLIS.2))
- [Hunyuan3D-2](https://github.com/Tencent-Hunyuan/Hunyuan3D-2): High-resolution open-source 3D asset creation system (Text/Image-to-3D geometry and PBR textures) with an official Blender add-on. `[open-source]`
- [ComfyUI-Hunyuan3d-2-1](https://github.com/visualbruno/ComfyUI-Hunyuan3d-2-1): ComfyUI wrapper for [Hunyuan3D-2.1](https://github.com/Tencent-Hunyuan/Hunyuan3D-2.1) bringing fully open-source PBR texture synthesis workflows to Blender + ComfyUI pipelines. `[open-source]` ([Hunyuan3D-2.1](https://github.com/Tencent-Hunyuan/Hunyuan3D-2.1))
- [ComfyUI-LATO2](https://github.com/sakalond/ComfyUI-LATO2): ComfyUI low-poly remeshing node designed to convert dense AI-generated meshes (`TRELLIS.2`, `Hunyuan3D`, 3D scans) into clean quad/low-poly topology. `[GPL]`
- [AssetFurnace](https://github.com/Bingeljell/image-to-3dlab): Complete open-source image-to-3D pipeline generating textured, rigged, and animated game characters locally via TRELLIS.2 and Hunyuan3D. `[open-source]`
- [Dream Textures](https://github.com/carson-katri/dream-textures): Stable Diffusion built-in to the Blender shader editor, image editor, and compositor. `[GPL]`
- [AI Render](https://github.com/benrugg/AI-Render): Stable Diffusion in Blender. This add-on renders an AI generated image based on a text prompt and your scene. `[open-source]`
- [Pallaidium](https://github.com/tin2tin/Pallaidium): Generative AI movie studio integrated into the Blender Video Sequence Editor (VSE) for text, image, audio, and video generation. `[GPL]`

## Synthetic Data & Benchmarks

### Synthetic Data & Vision AI

- [BlenderProc](https://github.com/DLR-RM/BlenderProc): A procedural Blender pipeline for photorealistic training image generation. `[GPL]`
- [BlenderSynth](https://github.com/OllieBoyne/BlenderSynth): Blender scripting for generating synthetic datasets at scale. `[open-source]`
- [Kubric](https://github.com/google-research/kubric): Data generation pipeline by Google Research for creating semi-realistic synthetic multi-object videos with rich ground-truth annotations using Blender and PyBullet. `[open-source]`
- [SceneWeaver](https://github.com/Scene-Weaver/SceneWeaver): NeurIPS 2025 extensible, self-reflective agent framework for all-in-one 3D scene synthesis built on Infinigen and Blender. `[open-source]`

### Benchmarks & Prompts

- [BlenderWorld](https://github.com/QwenLM/BlenderWorld): Visual agent benchmark by QwenLM containing 223 tasks and 2,651 criteria evaluating editable 3D Blender scene creation from real-world references. `[MIT]`
- [BlenderGym](https://github.com/richard-guyunqi/BlenderGym-Open): CVPR VLM benchmark evaluating code-based 3D graphics editing in Blender across 245 scenes (procedural geometry, lighting, materials, blend shapes, and placement). `[open-source]`
- [BlenderAlchemy](https://github.com/ianhuang0630/BlenderAlchemyOfficial): ECCV 2024 Stanford research framework treating VLM-driven 3D Blender scene edits as iterative visual programs. `[open-source]`
- [Blender AI Arena](https://blenderai.org/): Community-driven benchmark, prompt sets, and blind Elo/Glicko-2 leaderboard comparing 3D generative AI models and agents in Blender.
- [Awesome Astra Prompts](https://github.com/TripoGrowthLab/awesome-astra-prompts): Curated 3D prompt collection and examples for generative AI models, games, and Blender scenes. `[open-source]`
